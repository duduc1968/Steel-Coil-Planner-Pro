# UI Fix v9.4.0.7 — Engineering Ruler Alignment

Based on v9.4.0.2.

## Changes
- Stowage Workspace Cargo Zone and engineering ruler share one longitudinal container and scale.
- Both use the same effective loaded-zone start/end values.
- Ruler shows loaded-zone lengths, AFT/FORE free distances, and gaps between multiple zones.
- Hold header shows occupied/free length and percentages.
- AFT/FORE labels retained.

## Unchanged
Geometry Engine, Optimizer, Progressive Cargo, Remaining Cargo, Validate/Unlock.
