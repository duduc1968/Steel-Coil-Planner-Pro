# UI Sprint v9.4.0.3 — Engineering Dimension Ruler

Scope: Stowage Workspace presentation only.

## UI-003
- Added an engineering ruler for validated/loaded cargo zones.
- Shows actual loaded length of every zone.
- Shows free distance from AFT to first loaded zone.
- Shows free distances between loaded zones.
- Shows free distance from last loaded zone to FORE.
- Values are derived from zone coordinates and allocated length.

## UI-004
- Added hold utilisation indicators:
  - occupied length and percentage;
  - free length and percentage.

No changes were made to Geometry Engine, Optimizer, Progressive Cargo, Remaining Cargo, Validate Zone, or Unlock Zone.
