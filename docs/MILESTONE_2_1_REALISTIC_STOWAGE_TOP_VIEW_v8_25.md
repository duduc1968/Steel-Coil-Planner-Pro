# Milestone 2.1 — Realistic Stowage Top View v8.25

## Changes

- Cargo-zone indicators in Stowage Workspace are displayed in a dedicated strip above each hold.
- Zone indicators retain their exact longitudinal From–To positions.
- The top-view hold rendering is taller and uses the full transverse width from port to starboard.
- Port, starboard, fore, aft, and centreline references were added for a more realistic plan view.
- Coil blocks remain restricted to the optimized cargo zones.
- Cargo Zones workspace and Foundation geometry/validation rules remain unchanged.
