# Steel Coil Planner Pro v10.2.0.2

## Hold 2 Upper Starboard hotfix

- Upper Port and Upper Starboard remain editable after zone validation.
- Changing either value rebuilds and revalidates the selected zone.
- Zone input synchronization now uses the selected zone's actual hold index,
  rather than relying on a potentially stale global active-hold index.
- Stowage synchronization no longer changes the user's active hold.

Validated Width Arrangement Engine rules remain unchanged.
