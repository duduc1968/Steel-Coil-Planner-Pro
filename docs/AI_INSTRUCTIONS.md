# Steel Coil Planner Pro – AI Instructions

## Mandatory rules
- Logic first, design second.
- Cross Section and Top View must use the same geometry model.
- Bottom Row can be Auto or Manual.
- Upper Row remains Manual.
- Wedge Auto must never create two wedge coils from one central gap.
- Two wedge coils are allowed only when the engine can prove two separate real support gaps exist, or when the user selects Manual.
- Marker must move from 0 m to maximum hold length.
- All holds should be visible in Multi-Hold Workspace.
