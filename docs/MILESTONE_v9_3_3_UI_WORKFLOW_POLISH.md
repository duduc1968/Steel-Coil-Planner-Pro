# Steel Coil Planner Pro v9.3.3 — UI & Workflow Polish

This maintenance release preserves the validated planning and width-arrangement engines.

## Changes

- Pointer cursor is shown for planning-mode choices, radio buttons, checkboxes, buttons, selectors, and other interactive controls.
- Clicking or tabbing into an enabled numeric input automatically selects the complete existing value.
- A default value such as `0` can therefore be replaced immediately without Backspace, Delete, or Ctrl+A.
- Switching to Required Cargo Weight focuses and selects the weight input.
- Pressing Enter in the selected zone's weight or tolerance field runs Optimize Preview.
- Version labels updated to v9.3.3.

## Preserved project convention

- Hold 1 is at the bow (forward).
- With bow shown to the right, Hold 1 is displayed at the far right and subsequent hold numbers increase toward the stern.
