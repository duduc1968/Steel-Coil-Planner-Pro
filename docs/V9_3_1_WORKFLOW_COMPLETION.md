# Steel Coil Planner Pro v9.3.1 — Workflow Completion

## Corrected workflow

- Every newly created zone starts in **Required Cargo Weight** mode so the requested tonnage can be entered immediately.
- Switching between **Fixed Zone Length** and **Required Cargo Weight** refreshes the zone editor instantly.
- The weight input is enabled immediately in Required Cargo Weight mode.
- Legacy automatically-created Remaining Cargo zones are migrated into editable draft zones.
- Each optimization continues to use only cargo remaining after validated zones.
- Row gap and actual coil widths remain part of all longitudinal calculations.

The validated Width Arrangement, Geometry, Valley and Validation engines are unchanged.
