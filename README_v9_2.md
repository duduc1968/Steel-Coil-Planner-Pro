# Steel Coil Planner Pro v9.2

Test sequence:

1. Import a cargo list or use Simulation Mode.
2. Draw a Cargo Zone and enter required weight and tolerance.
3. Press **Optimize Cargo**.
4. Open **Cargo Pool** to inspect Available / Reserved / Loaded in Plan coils.
5. Open **Stowage Workspace** to verify that the exact reserved coils are used in the selected zone.
6. Press **Release Cargo** to remove the reservation and test reallocation to another zone.

Validated foundation engines remain unchanged.
